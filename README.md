## Описание задачи

Программа запрашивает у пользователя число N, которое должно быть положительным и меньше 1000. Затем число разбивается на цифры (сотни, десятки, единицы), вычисляется их произведение, после чего программа проверяет, является ли полученное произведение трёхзначным числом.

## Пошаговое описание работы программы

**1. Подключение библиотеки**

Подключаем стандартную библиотеку ввода-вывода stdio.h. Без неё не будут работать функции вывода на экран (printf) и ввода с клавиатуры (scanf_s).

**2. Объявление переменных**

- N — число, которое введёт пользователь;
- a, b, c — первая (сотни), вторая (десятки) и третья (единицы) цифры числа;
- p — произведение этих цифр.

**3. Приглашение к вводу**

Программа печатает подсказку «Введите число N (N < 1000)», чтобы пользователь понял, что от него требуется.

**4. Ввод числа и проверка корректности ввода**

Функция scanf_s читает целое число с клавиатуры и записывает его в N. Функция возвращает количество успешно считанных значений: если пользователь ввёл, например, буквы, вернётся 0, а не 1. В этом случае печатается сообщение «Ошибка ввода» и работа функции завершается с кодом 1 — программа сообщает о нештатном завершении. Дальнейшие вычисления при этом не выполняются.

**5. Проверка диапазона числа**

Логика задания рассчитана на трёхзначные числа, поэтому N должно быть строго больше 0 и меньше 1000. Отдельная проверка N <= 0 отсекает ноль и отрицательные числа: для них разбиение на цифры через деление работает неправильно (например, у числа -123 первая цифра получилась бы равной -1). Если условие не выполнено, программа выводит сообщение о некорректном диапазоне и переходит к завершению работы.

**6. Разбиение числа на цифры**

Разбор на примере N = 257:

- a = 257 / 100 — целочисленное деление даёт 2, это цифра сотен;
- b = (257 / 10) % 10 — сначала 257 / 10 = 25, затем остаток от деления 25 % 10 = 5, это цифра десятков;
- c = 257 % 10 — остаток от деления на 10 равен 7, это цифра единиц.

**7. Вычисление произведения**

Полученные цифры перемножаются: p = a * b * c. Для примера выше: 2 x 5 x 7 = 70.

**8. Вывод результата и проверка на трёхзначность**

Сначала программа выводит само произведение. Затем проверяется, лежит ли p в диапазоне от 100 до 999 — именно такие числа являются трёхзначными. Если произведение попало в диапазон, выводится сообщение о том, что произведение является трёхзначным числом, иначе — что не является. В примере выше 70 < 100, поэтому программа сообщит, что произведение не трёхзначное. А для N = 999 получилось бы 9 x 9 x 9 = 729 — уже трёхзначное.

**9. Завершение работы**

Функция возвращает 0 — стандартный код успешного завершения. Сюда программа попадает в любом случае при корректном вводе: и если диапазон нарушен, и если все вычисления выполнены успешно.

## Общая логика программы

Ввод → проверка ввода → проверка диапазона → разбор на цифры → вычисление произведения → вывод результата → завершение работы.
